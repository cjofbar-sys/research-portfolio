# Integration with the existing website

The research portfolio is displayed through the existing Lovable **Imagined And Possible Futures** project, which uses TanStack Start and supports English, Portuguese and Spanish. Its working research route is `/research`.

This repository is the public source for approved scientific documentation, code demonstrations and evidence references. It is not a replacement for the website's source code. Avoid copying the website's entire codebase into this repository.

## Editorial integration

- Each published research card should link to an exact document or stable GitHub path in this repository.
- The website should summarize claims only after scientific and disclosure review of their source.
- Maintain site translations in the site's actual localization architecture.
- Do not advertise this route as live at the custom domain until deployment has been checked.
- Do not automate ingestion of private repos or expose unpublished manuscripts.

Future automated ingestion is conditional on content validation; simple stable links are sufficient for the first release.
