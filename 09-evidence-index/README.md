# Public evidence index

This directory contains references safe for public distribution. Detailed proof records, confidential documents and application-specific strategic assessments belong in a **separate private repository or workspace**.

| Field | Meaning |
| --- | --- |
| ID | Stable public evidence identifier |
| Claim | Precisely worded, limited assertion |
| Source | Publicly available verification |
| Status | Verified, under review, proposed or synthetic |
| Role | Researcher's attributable contribution |
| Disclosure | Authorization and limitations |

Do not publish participant-level datasets, personal identifiers, internal project specifications, credentials or links that presume public access to private resources.

Initial metadata will be added after documentary review.
